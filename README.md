# تطبيق البقال (Albakal)

منصة وتطبيق أندرويد متكامل للبقالة والسوبرماركت يربط بين العملاء والتجار والمشرفين والإدارة، مع دعم كامل للمحافظات والمناطق المصرية، سداد المديونيات برفع الإيصالات، وإدارة الإعلانات الممولة.

## 🌟 مميزات التطبيق

1. **شاشة دخول موحدة ونظيفة:**
   - شاشة تسجيل دخول موحدة لجميع الأدوار (العملاء، التجار، المشرفين، الإدارة العليا) بحقول إدخال فارغة تماماً وبدون أي بيانات وهمية.

2. **مطابقة المحافظات والمناطق:**
   - يختار العميل والتاجر المحافظة والمركز/المنطقة (القاهرة، الجيزة، الإسكندرية، الدقهلية، الشرقية، القليوبية، البحيرة، الغربية، المنوفية، إلخ).
   - تظهر للعميل المتاجر والسلع المتوافقة جغرافياً في منطقته.

3. **منتجات حقيقية في متجر العملاء:**
   - إزالة كافة المنتجات الوهمية.
   - تظهر فوراً فقط المنتجات الحقيقية التي يدرجها التجار المسجلون أو تضيفها الإدارة لمتاجرهم.

4. **إضافة المنتجات مع الصور من الهاتف:**
   - منتقي صور أندرويد الحديث (`PickVisualMedia`) بدون أذونات خطرة.
   - إمكانية قيام الإدارة والمشرفين بإضافة بضائع مباشرة لأي متجر تاجر معتمد.

5. **إثبات دفع مديونية التاجر بصورة الإيصال:**
   - يمكن للتاجر رفع صورة إشعار التحويل البنكي أو إيصال فودافون كاش / إنستا باي عند طلب سداد المديونية.
   - مراجعة وتكبير صورة الإيصال في لوحة تحكم الإدارة قبل الاعتماد وخصم المديونية.

6. **لوحة تحكم الإعلانات الممولة:**
   - رفع إعلانات مصورة من الهاتف وتحديد مدة الإعلان بالأيام مع حساب تاريخ الانتهاء وتفعيل/إيقاف الإعلان.

7. **إنذار صوتي واهتزاز مستمر للطلبات:**
   - تنبيه مستمر للتجار والكباتن عند ورود أي طلب جديد حتى فتحه.

8. **نظام صلاحيات المشرفين:**
   - الإدارة العليا تمنح صلاحيات مخصصة لكل مشرف، مع أمان وتشفير PIN وحساب المدير العام.
